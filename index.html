Kandungan sumber terbuka IBM Quantum​

IBM menyediakan banyak bahan pembelajaran pengkomputeran kuantum — semuanya sumber terbuka di bawah CC BY-SA 4.0:

  • Learning — Kursus berstruktur dari asas kuantum hingga topik lanjutan
  • Tutorials — Lebih 40 tutorials tentang transpilation, error mitigation dan lain-lain
  • Documentation — Panduan dan rujukan API untuk Qiskit
  • Source repo — Semua kandungan di GitHub

Quantum Platform mereka sentiasa terkini dan direka dengan baik — tempat terbaik untuk membaca, belajar dan rujukan.

Apa yang projek ini tambah​

Dokumentasi Qiskit IBM adalah sumber terbuka (CC BY-SA 4.0), tetapi aplikasi web mereka tidak. doQumentation menambah frontend sumber terbuka dengan pelaksanaan kod langsung, suntikan kelayakan automatik dan mod simulator.

Boleh digunakan di mana-mana — dari GitHub Pages ke Docker ke RasQberry. Lihat semua ciri.

Apabila anda bersedia untuk lebih banyak lagi​

doQumentation membantu anda mengambil langkah pertama dengan Qiskit — membaca, menjalankan kod, dan meneroka — tanpa perlu memasang apa-apa. Apabila anda maju, pergi ke platform rasmi IBM:

  • Jalankan pada perkakasan sebenar — cipta akaun IBM Cloud percuma dan kejadian Open Plan untuk menjalankan litar pada komputer kuantum sebenar.
  • Kandungan terkini — platform pembelajaran Qiskit IBM mempunyai kursus, tutorial dan tambahan terkini (sebahagiannya mungkin belum ada dalam doQumentation).
  • Membangun secara tempatan — pasang Qiskit pada komputer riba anda sendiri untuk kerja pembangunan yang serius.

Dibina berdasarkan dokumentasi sumber terbuka IBM Quantum. Terima kasih kepada pasukan IBM Quantum kerana menjadikan kandungan ini tersedia secara bebas di bawah CC BY-SA 4.0.

Pelaksanaan kod​

Klik Run pada mana-mana blok kod. Klik pertama memulakan kernel Jupyter melalui Binder atau IBM Code Engine. Selepas itu, pelaksanaan adalah serta-merta.

  • Mod Simulator (tiada akaun diperlukan) — Aktifkan Mod Simulator untuk jalankan semua notebook dengan AerSimulator atau FakeBackends model hingar. Tiada persediaan diperlukan.

  • Perkakasan IBM Quantum — Masukkan token API dan CRN anda dalam Tetapan sekali sahaja — kelayakan disuntik secara automatik pada setiap pelaksanaan. Cipta akaun percuma jika belum ada.

Backend pelaksanaan yang tersedia

Setiap tutorial mempunyai blok kod yang boleh dilaksanakan. Klik Run untuk melaksanakannya menggunakan salah satu daripada empat backend:

  1. Binder (lalai pada GitHub Pages) — Kernel Jupyter jauh percuma melalui mybinder.org
  2. IBM Code Engine — Jupyter tanpa pelayan pada akaun IBM Cloud anda. Cold start dalam beberapa saat berbanding minit. Sediakan
  3. Jupyter Tempatan (Docker / RasQberry) — Sambung ke pelayan Jupyter tempatan dengan Qiskit diprapasang
  4. Pelayan tersuai — Tunjuk ke mana-mana endpoint Jupyter dalam Tetapan

Tiada akaun IBM Quantum? Aktifkan Mod Simulator dalam Tetapan untuk menjalankan semua kod tanpa perlu mendaftar.

Apabila berbilang backend tersedia, pilih yang mana satu untuk digunakan dari Tetapan.

Pilihan penggunaan

doQumentation tersedia sebagai:

  • GitHub Pages — Laman statik dengan Binder atau IBM Code Engine untuk pelaksanaan kod jauh
  • Docker — Full stack secara tempatan, mampu beroperasi luar talian
  • RasQberry — Self-hosted pada Raspberry Pi dengan kernel Jupyter tempatan
Jalankan secara tempatan dengan Podman / Docker

Pasang Podman Desktop atau Docker Desktop (Mac / Windows / Linux), kemudian jalankan:

# Full stack: site + Jupyter + Qiskit (~3 GB)
podman run -p 8080:80 -p 8888:8888 ghcr.io/janlahmann/doqumentation:jupyter

Buka http://localhost:8080 — pelaksanaan kod berfungsi secara tempatan, tiada masa tunggu Binder.

Untuk versi ringan tanpa pelaksanaan kod tempatan (~60 MB):

# Static site only — code execution still works via Binder
podman run -p 8080:80 ghcr.io/janlahmann/doqumentation:latest

Guna Docker sebaliknya? Gantikan sahaja podman dengan docker — arahan adalah sama. Image adalah multi-arch (linux/amd64 + linux/arm64), jadi Apple Silicon Mac berfungsi secara native.
