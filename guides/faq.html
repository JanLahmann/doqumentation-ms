Soalan lazim (FAQ)

Untuk soalan lazim khusus tentang mod pelaksanaan, lihat panduan FAQ mod pelaksanaan Qiskit Runtime.

Bagaimana saya memetik Qiskit dalam penyelidikan saya?​

Petik Qiskit dengan menggunakan fail BibTeX yang disertakan.

Bagaimana saya memetik komputer IBM Quantum dalam penyelidikan saya?​

Untuk kertas penyelidikan, kami menggalakkan penulis mengakui IBM Quantum® dengan menggunakan:

Kami mengakui penggunaan perkhidmatan IBM Quantum untuk kerja ini. Pandangan yang dinyatakan adalah milik penulis, dan tidak mencerminkan dasar atau pendirian rasmi IBM atau pasukan IBM Quantum.

Rujukan kertas harus menggunakan petikan berikut:

IBM Quantum. https://quantum.cloud.ibm.com/, YYYY

Unit pemprosesan kuantum dalam kertas harus dirujuk dengan nama uniknya (contohnya, ibmq_vigo) dan secara pilihan menambahkan versi (contohnya, ibmq_vigo v1.0.2). Kami juga menggalakkan merujuk kepada pemproses tersebut. Contohnya:

Dalam kertas ini kami menggunakan ibmq_vigo, yang merupakan salah satu pemproses IBM Quantum Canary.

Contoh memetik program IBM Quantum:

IBM Quantum (2025). Primitif Estimator (Versi x.y.z) [perisian komputer]. https://quantum.cloud.ibm.com/

Bagaimana saya memetik IBM Quantum Composer dalam penyelidikan saya?​

Contoh petikan untuk IBM Quantum Composer:

IBM Quantum Composer. 2025. url: https://quantum.cloud.ibm.com/composer

Saya tidak nampak sesuatu dalam antara muka pengguna, seperti tugas pentadbiran saya.​

Cuba pilih akaun yang berbeza daripada penukar akaun di pengepala antara muka IBM Quantum Platform.

Saya hanya menggunakan Open Plan, tetapi saya terpaksa memasukkan kad kredit saya. Adakah saya akan dicaj?​

Anda tidak akan dicaj melainkan anda mencipta instans Pay-As-You-Go dan menggunakannya untuk menghantar beban kerja ke QPU. Lihat Urus kos untuk arahan menetapkan had kos dan untuk mengetahui cara-cara lain mengurus kos.

Apakah perbezaan antara kunci API dan token API?​

Tiada perbezaan. Istilah kunci API dan token API digunakan secara bergantian. Anda akan melihat kedua-dua istilah dalam dokumentasi kerana antara muka yang berbeza menggunakan istilah yang berbeza.

Apakah perbezaan antara token API dan token bearer?​

Token API ialah kelayakan jangka panjang yang digunakan untuk mengesahkan diri kepada perkhidmatan Qiskit Runtime. Token bearer ialah kelayakan sementara yang digunakan untuk mengesahkan diri kepada REST API dalam persekitaran yang tidak dipercayai. Token bearer tidak boleh digunakan untuk mengesahkan diri kepada perkhidmatan Qiskit Runtime.

Adakah saya perlu memilih rantau tempat saya tinggal?​

Tidak. Anda boleh menggunakan mana-mana rantau. Rantau menentukan di mana job dijalankan dan di mana data disimpan. Selain itu, anda hanya boleh melihat dan menggunakan instans yang dicipta dalam instans yang anda log masuk. Perlu diingat bahawa hanya rantau us-east yang menyokong Open Plan.

Bolehkah saya sambung melalui pelayan proksi?​

Ya, tetapi anda mesti menggunakan Qiskit Runtime v0.44.0 atau lebih baharu.

Apakah dasar pengekalan data?​

IBM menyimpan data job dan penggunaan anda (yang tidak dipadam) selama tiga tahun selagi anda terus menggunakan perkhidmatan Qiskit Runtime.

Apa yang berlaku kepada pengedaran Python seperti Qiskit Aer, Qiskit Nature, dan Qiskit Experiments?​

Sejak keluaran Qiskit SDK v1.0, arahan pip install qiskit hanya akan memasang Qiskit SDK sahaja. Ini bermakna beberapa modul yang pernah anda gunakan sebelum ini, seperti qiskit-aer atau qiskit-nature, kini perlu dipasang secara berasingan.

Sebelum keluaran Qiskit SDK v1.0, Qiskit terdiri daripada banyak pengedaran Python yang berbeza, seperti qiskit-terra, teras pengkompil; qiskit-aer, simulator berprestasi tinggi; pembekal IBM Quantum® asal; dan beberapa pakej yang kini lapuk yang menyediakan ciri algoritma atau eksperimen tertentu yang bersifat penerokaan.

Pakej perisian yang berasingan ini digabungkan menjadi apa yang dikenali sebagai metapackage Qiskit, yang membolehkan pengguna memasang semua komponen ini bersama-sama melalui pip install qiskit. Seni bina metapackage ini dihapuskan dengan keluaran Qiskit SDK v1.0, dan kini setiap pengedaran perisian individu perlu dipasang secara berasingan.

Jika anda ingin memasang pakej yang sebelum ini disertakan dalam metapackage Qiskit, lawati ekosistem Qiskit untuk mencari pelbagai pakej yang sesuai dengan keperluan anda. Anda juga boleh membaca panduan migrasi v1.0 untuk maklumat lanjut tentang perubahan ini.

Bagaimana saya menutup akaun IBM Cloud saya?​

Cari arahan di halaman Menutup akaun.

Mengapa saya melihat mesej bahawa akaun saya tidak aktif semasa cuba log masuk?​

Jika anda melihat mesej "This account is inactive", lawati dokumentasi IBM Cloud untuk mengetahui sebab dan cara menyelesaikannya, atau akses IBM Cloud untuk mengesahkan sama ada terdapat sebarang tindakan yang perlu anda selesaikan dalam akaun anda.

Apakah impak hanyutan peranti?​

Impak hanyutan peranti (prestasi perkakasan yang merosot dari semasa ke semasa) bergantung kepada banyak faktor, seperti masa kalibrasi terakhir dijalankan, eksperimen spesifik yang dilakukan, sebarang aktiviti TLS, dan sebagainya. Jika beban kerja tertentu sangat sensitif terhadap nilai ralat parameter peranti, anda boleh melakukan penanda aras parameter peranti masa nyata dengan mengikuti tutorial ini dalam IBM Quantum Learning.
