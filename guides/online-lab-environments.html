Persekitaran makmal dalam talian

Selain memuat turun dan memasang Qiskit untuk bekerja pada mesin tempatan anda, terdapat beberapa pilihan tersedia bagi mereka yang lebih suka bekerja dalam persekitaran pembangunan dalam talian.

Beberapa pembekal menawarkan persekitaran Jupyter dalam talian dengan Qiskit diprapasang untuk onboarding yang cepat dan mudah. Pembekal yang disyorkan ini termasuk pembekal perkhidmatan awan OVHcloud dan platform awan pembangunan perisian kuantum qBraid.

Persekitaran notebook yang disyorkan dengan Qiskit diprapasang​

Persekitaran notebook Jupyter dalam talian tambahan seperti IBM Watson® Studio, Google Colab, dan Microsoft Azure Machine Learning Studio boleh digunakan untuk bekerja dengan Qiskit dengan mengikuti arahan yang sesuai.

Notebook AI OVHcloud​

Pengguna OVHcloud Public Cloud dan OVHcloud Startup boleh menggunakan notebook kuantum OVHcloud mereka untuk mengakses Qiskit dan menyerahkan kerja ke QPU IBM® dengan akaun IBM Quantum® atau IBM Cloud® mereka. Untuk mengetahui lebih lanjut, lawati halaman Dokumentasi dan tutorial OVHcloud.

nota

Notebook AI OVHcloud tidak tersedia di sesetengah rantau, seperti Amerika Syarikat. Selain itu, antara muka pengguna mungkin kelihatan berbeza di rantau yang berbeza.

Ikuti langkah-langkah ini untuk bermula:

  1. Buat akaun IBM Cloud.
  2. Sediakan akaun OVHcloud.
  3. Buat projek OVH Public Cloud.
  4. Ikuti langkah-langkah dalam Lancarkan Notebook AI pertama anda, pilih Qiskit untuk rangka kerja.

qBraid Lab​

Pengguna Qiskit boleh menggunakan persekitaran Python yang telah dikonfigurasi oleh qBraid dengan mengikuti arahan berikut. Untuk maklumat lanjut, lihat Dokumentasi qBraid.

  1. Sediakan akaun percuma qBraid.
  2. Buat persekitaran Lab.
  3. Lancarkan qBraid Lab, klik ikon ENVS di sebelah kanan, klik + ADD di bahagian atas bar sisi baru, dan cari Qiskit. Klik versi yang ingin anda gunakan, kemudian klik Install.
  4. Buat notebook Jupyter dengan mengklik Python 3 [Qiskit] dalam bahagian Notebook.
  5. Anda boleh memasang sebarang pakej Python tambahan (seperti Qiskit v1.2) dalam sel notebook dengan menjalankan %pip install [package_name]. Untuk maklumat lanjut, lihat topik Arahan Pip (magic).

Persekitaran notebook tambahan untuk pengguna Qiskit​

Untuk platform tanpa Qiskit dikonfigurasi terlebih dahulu, arahan persediaan adalah serupa, kecuali anda perlu memasang Qiskit secara manual. Anda akan mencipta akaun, memulakan projek baru (atau notebook atau ruang kerja, bergantung pada platform), dan memasang Qiskit.

IBM Watson Studio​

  1. Sediakan percubaan percuma Watson Studio.
  2. Buat Projek Watson Studio.
  3. Untuk memasang pakej Qiskit dan kebergantungan yang diperlukan, buka notebook baru dan jalankan arahan berikut: 
    !pip install qiskit pylatexenc !yes | pip uninstall simplejson

Google Colab​

  1. Buat akaun Google.
  2. Pergi ke halaman pendaratan Google Colab dan log masuk dengan akaun Google anda.
  3. Buat notebook Colab dan pasang Qiskit dengan menjalankan arahan berikut: 
    %pip install qiskit

Microsoft Azure Machine Learning Studio​

  1. Buat akaun Azure.
  2. Buat ruang kerja.
  3. Buat notebook Jupyter dalam ruang kerja anda.
  4. Dari notebook, jalankan arahan ini untuk memasang Qiskit: 
     %pip install qiskit
