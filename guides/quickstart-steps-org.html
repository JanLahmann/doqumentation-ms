Konfigurasi IBM Quantum Platform untuk sesebuah organisasi

Ikuti langkah-langkah ini untuk menyediakan IBM Quantum Platform.

1. Konfigurasi tetapan IAM​

Pertama, konfigurasi tetapan berikut dalam akaun IAM pentadbir. Untuk menyemak dan mengkonfigurasi tetapan ini, pergi ke Manage → IAM → Settings.

  • Keterlihatan senarai pengguna menentukan sama ada pengguna boleh melihat antara satu sama lain, tanpa mengira tugasan projek. Tetapan enabled mengehadkan keterlihatan pengguna. Maksudnya, pengguna dalam akaun anda tidak dapat melihat antara satu sama lain, walaupun mereka boleh mengakses sumber yang sama. Pilih nilai yang sesuai untuk persekitaran anda. Lihat Mengawal keterlihatan pengguna untuk maklumat lanjut.
  • Penciptaan kunci API mengawal sama ada pengguna boleh mencipta kunci API. Dalam IBM Quantum Platform, kunci API biasa digunakan. Jika kunci API digunakan, pilih disabled. Sebagai alternatif, anda boleh memberi kebenaran khusus kepada setiap pengguna.

2. (Pilihan) Cipta kumpulan sumber​

Langkah ini boleh dilangkau jika anda menggunakan kumpulan akses yang merujuk terus kepada instans perkhidmatan IBM Quantum.

Jika anda memilih untuk menggunakan kumpulan sumber, pergi ke Manage → Account → Resource groups (dalam Account resources) dan klik Create.

3. Cipta instans perkhidmatan IBM Quantum​

Jika anda telah mencipta instans perkhidmatan IBM Quantum, langkau langkah ini.

  • Jika anda menggunakan kumpulan sumber, pastikan anda mencipta instans perkhidmatan pada kumpulan sumber yang sesuai.
  • Nama instans perkhidmatan, seperti QR-ml, diperlukan untuk rujukan kumpulan akses.

Ikuti langkah-langkah dalam Sediakan untuk menggunakan IBM Cloud untuk arahan.

4. Cipta kumpulan akses untuk projek​

Pertama, cipta peranan tersuai yang membolehkan pengguna melakukan tindakan untuk bekerja dengan instans perkhidmatan IBM Quantum. Seterusnya, cipta kumpulan akses untuk setiap projek dan berikan kumpulan tersebut set kebenaran minimum yang diperlukan untuk bekerja dengan sumber projek.

5. Sediakan penyedia ID anda dan tugaskan pengguna​

Ikuti langkah-langkah dalam topik yang sesuai, bergantung pada penyedia ID yang anda pilih:

  • Gunakan IBM Cloud® sebagai penyedia ID untuk pengguna yang mempunyai akaun IBM Cloud
  • Gunakan IBM Cloud sebagai penyedia ID untuk pengguna yang tidak mempunyai akaun IBM Cloud
  • Gunakan penyedia ID selain IBM Cloud untuk pengguna yang tidak mempunyai akaun IBM Cloud
  • Jemput pengguna dan urus akses mereka

6. Konfigurasi tembok api anda​

Untuk mengkonfigurasi tembok api anda bagi membolehkan akses ke titik akhir API IBM Quantum, tambahkan URL berikut ke senarai benarkan anda:

  • Perkhidmatan global IBM Cloud: 
    cloud.ibm.com
    iam.cloud.ibm.com
    api.global-search-tagging.cloud.ibm.com
    globalcatalog.cloud.ibm.com
    resource-controller.cloud.ibm.com
  • Perkhidmatan IBM Quantum Qiskit Runtime - rantau us-east: 
    quantum.cloud.ibm.com
    s3.us-east.cloud-object-storage.appdomain.cloud
  • Perkhidmatan IBM Quantum Qiskit Runtime - rantau eu-de: 
    eu-de.quantum.cloud.ibm.com
    s3.direct.eu-de.cloud-object-storage.appdomain.cloud
  • Perkhidmatan pratonton IBM Quantum Qiskit Functions: 
    qiskit-serverless.quantum.ibm.com
