Memahami tanggungjawab anda apabila menggunakan Qiskit Runtime

Semak bahagian-bahagian berikut untuk tanggungjawab khusus anda dan IBM® apabila anda menggunakan Qiskit Runtime. Untuk terma penggunaan keseluruhan, lihat Terma dan Notis untuk IBM Cloud®.

Pengurusan insiden dan operasi​

Pengurusan insiden dan operasi termasuk tugas-tugas seperti pemantauan, pengurusan peristiwa, ketersediaan tinggi, penentuan masalah, pemulihan, dan sandaran serta pemulihan keadaan penuh.

TugasTanggungjawab IBMTanggungjawab anda
Pengurusan kesihatan infrastruktur
  • Secara berterusan menyampaikan ciri, kemas kini, dan pembaikan pepijat baharu mengikut keperluan secara telus.
  • Menyediakan notifikasi untuk penyelenggaraan terancang, buletin keselamatan, atau gangguan tidak dirancang.
  • Tetapkan keutamaan untuk menerima e-mel tentang notifikasi perkhidmatan.
  • Pantau halaman status IBM Cloud untuk pengumuman umum.
Pemantauan dan notifikasi kesihatan infrastruktur
  • Memulihkan semua isu persekitaran infrastruktur.
  • Memaklumkan pelanggan tentang insiden yang berkenaan.
  • Menentukan kesan setiap insiden yang dilaporkan.
  • Hubungi Sokongan IBM mengikut keperluan.
Mengekalkan SLA ketersediaan tinggi IBM CloudMengendalikan Qiskit Runtime mengikut Perjanjian Tahap Perkhidmatan (SLA) Awam IBM Cloud.Ikuti amalan terbaik ketersediaan tinggi.

Pengurusan perubahan​

Pengurusan perubahan termasuk tugas-tugas seperti penggunaan, konfigurasi, naik taraf, tampalan, perubahan konfigurasi, dan pemadaman.

TugasTanggungjawab IBMTanggungjawab anda
Naik taraf versi utamaMenyediakan ketersediaan dan alat untuk kemas kini versi utama.Pindah ke versi yang disokong sebelum tamat sokongan untuk versi lama.
Perubahan versi APIPenomboran API REST.Integrasikan dengan versi API REST yang dikehendaki.
Kemas kini, pembaikan, dan ciri baharu
  • Menyediakan kemas kini, pembaikan pepijat, dan ciri baharu secara berkala, secara telus mengikut model penghantaran berterusan.
  • Menyiarkan notifikasi untuk perubahan yang memberi kesan kepada pelanggan.
  • Tetapkan keutamaan untuk menerima notifikasi e-mel dan pantau halaman status IBM Cloud untuk pengumuman umum.
  • Baca notifikasi yang dijana sistem dan pengumuman platform, dan ambil tindakan yang sesuai.

Pengurusan identiti dan akses​

Pengurusan identiti dan akses termasuk tugas-tugas seperti pengesahan, kebenaran, pengurusan dasar kawalan akses, dan meluluskan, memberikan, dan membatalkan akses.

TugasTanggungjawab IBMTanggungjawab anda
Kawalan identiti dan aksesMenyediakan kemampuan untuk mengurus dan menyekat akses kepada sumber melalui IBM Cloud.Berikan, batalkan, dan urus akses kepada sumber melalui Pengurusan Identiti dan Akses Cloud (IAM).
Pengesahan perkhidmatanMemastikan bahawa hanya pengguna yang disahkan mempunyai akses kepada perkhidmatan dan sumber Qiskit Runtime anda.
  • Lindungi kunci API anda daripada akses tanpa kebenaran.
  • Putar dan kemas kini kunci API anda mengikut keperluan dasar keselamatan anda.
KebolehperhatianMembenarkan integrasi IBM Cloud Activity Tracker Event Routing untuk mengaudit tindakan pengguna.Sediakan IBM Cloud Activity Tracker Event Routing atau fungsi lain untuk menjejak aktiviti pengguna.

Pematuhan keselamatan dan peraturan​

Pematuhan keselamatan dan peraturan termasuk tugas-tugas seperti pelaksanaan kawalan keselamatan dan pensijilan pematuhan.

TugasTanggungjawab IBMTanggungjawab anda
Umum
  • Mengekalkan kawalan yang setara dengan pelbagai piawaian pematuhan industri.
  • Memantau, mengasingkan, dan memulihkan fungsi perkhidmatan.
  • Memantau dan melaporkan kesihatan antara muka perkhidmatan.
Memastikan bahawa data peribadi dan terkawal tidak disediakan.
KelemahanMemantau untuk mengesan kelemahan dan isu pematuhan keselamatan.
  • Sentiasa maklum tentang kemungkinan kelemahan dan isu keselamatan melalui buletin keselamatan yang menyediakan tindakan pemulihan yang berpotensi.
  • Semak bahagian keselamatan repositori Qiskit GitHub. Semua kelemahan keselamatan disiarkan di sana.
  • Semak laman web status IBM Cloud untuk mencari pengumuman dan buletin keselamatan tentang peristiwa utama yang mempengaruhi platform IBM Cloud, infrastruktur, dan perkhidmatan utama.
PenyulitanMenyulit data apabila ia dihantar pada mana-mana rangkaian awam dan dalam rangkaian pusat data peribadi Perkhidmatan Cloud. Kaedah penyulitan seperti HTTPS dan TLS digunakan untuk melindungi data dalam pergerakan.Memastikan, mengikut keperluan, bahawa sambungan anda disulitkan dari hujung ke hujung.
Keselamatan
  • Memastikan keselamatan data pada cakera dan data dalam pergerakan dalam infrastrukturnya.
  • Menyediakan perkhidmatan selamat yang mematuhi piawaian utama.
Hadkan akses pengguna kepada sumber dan kumpulan sumber yang sesuai.

Pemulihan bencana​

TugasTanggungjawab IBMTanggungjawab anda
UmumMemulihkan atau membina semula persekitaran peruntukan dan sumber dalam rantau yang terjejas.
  • Pantau keadaan instans dan sumber.
  • Peruntukkan instans perkhidmatan Qiskit Runtime baharu dalam rantau alternatif, jika tersedia.
Pemulihan perkhidmatanSecara automatik memulihkan dan memulihkan keupayaan perkhidmatan Qiskit Runtime kepada operasi normal.Hantar semula sebarang kerja yang terjejas selepas pemulihan.
Sandaran data konfigurasi penggunaIBM tidak bertanggungjawab untuk sandaran data konfigurasi pengguna.Sandaran sebarang data konfigurasi, mengikut keperluan.
Sandaran dan pemulihan beban kerjaIBM tidak bertanggungjawab untuk sandaran atau pemulihan data beban kerja pengguna.Sandaran dan pemulihan beban kerja anda, mengikut keperluan.
