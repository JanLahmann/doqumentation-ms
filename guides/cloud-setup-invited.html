Sediakan akaun IBM Cloud anda - pengguna yang dijemput

Jika anda tidak mempunyai jemputan daripada pentadbir untuk menyertai akaun yang telah disediakan oleh pentadbir, hubungi pentadbir anda. Jika anda perlu menyediakan akaun sendiri, ikuti langkah dalam Sediakan akaun IBM Cloud anda.

Anda boleh menjalankan beban kerja pada unit pemprosesan kuantum (QPU) IBM® dengan menyediakan akaun di IBM Cloud®. Anda juga perlu memasang dan menyediakan Qiskit dan Qiskit Runtime.

Akaun pengguna anda dikaitkan dengan satu atau lebih instans, yang dikenal pasti oleh Cloud Resource Names (CRN) yang memberikan akses ke perkhidmatan IBM Quantum. Selain itu, token API unik (juga dipanggil kunci) diberikan kepada setiap akaun, membolehkan akses IBM Quantum dari Qiskit. Untuk arahan memilih instans tertentu, lihat Sambung ke instans.

nota

Papan pemuka IBM Quantum Platform dan halaman Instans menyenaraikan instans yang boleh anda akses.

Sediakan untuk menggunakan IBM Cloud​

Sebelum anda mula​

  1. Terima jemputan e-mel.

  2. Log masuk dengan akaun IBMid atau Google. Perlu diambil perhatian bahawa profil yang anda gunakan untuk log masuk ke IBM Cloud atau IBM Quantum Platform dalam langkah ini bukan akaun IBM Cloud anda. Selepas log masuk, sahkan maklumat anda dan terima jemputan untuk menyertai akaun.

  3. Navigasi kembali ke IBM Quantum Platform.

  4. Pastikan akaun dan rantau yang betul dipilih dalam penukar akaun di pengepala, seperti yang ditunjukkan dalam imej berikut.

    • Pilih akaun yang dijemput dalam e-mel.
    • Rantau mengawal di mana kerja anda dijalankan dan di mana data kerja disimpan. Anda boleh mengakses mana-mana rantau menggunakan kunci API yang sama, tetapi anda hanya boleh melihat dan mengakses instans yang dicipta dalam rantau yang anda log masuk.

2. Pilihan: Simpan kelayakan akses anda​

Jika anda menggunakan persekitaran Python yang dipercayai, seperti komputer riba peribadi, adalah disyorkan agar anda menggunakan kaedah save_account() untuk menyimpan kelayakan anda secara tempatan.

3. Sambungkan Qiskit dengan instans perkhidmatan anda​

  • Mulakan perkhidmatan dalam persekitaran Python yang dipercayai
  • Mulakan perkhidmatan dalam persekitaran yang tidak dipercayai (seperti komputer awam)
Nota
  • Ikuti arahan ini jika anda ingin menyambung menggunakan REST API dan bukannya menggunakan Qiskit.
  • Jika perlu, gunakan maklumat ini untuk mengkonfigurasi tembok api anda bagi membolehkan akses ke titik akhir API IBM Quantum.

Langkah seterusnya​

Cadangan
  • Gambaran keseluruhan pelan yang tersedia.
  • Konfigurasi Qiskit SDK secara tempatan.
  • Sediakan untuk menggunakan IBM Quantum Platform dengan REST API
  • Ikuti langkah dalam Hello world untuk menulis dan menjalankan atur cara kuantum.
  • Cuba tutorial.
