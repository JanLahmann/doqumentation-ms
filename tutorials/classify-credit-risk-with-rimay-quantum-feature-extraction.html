Kelaskan risiko kredit dengan Pengekstrakan Ciri Kuantum Rimay Kipu Quantum

nota

Qiskit Functions ialah ciri eksperimen yang hanya tersedia kepada pengguna Pelan Premium, Pelan Flex, dan Pelan On-Prem (melalui API IBM Quantum Platform) IBM Quantum®. Ia berstatus keluaran pratonton dan tertakluk kepada perubahan.

Anggaran penggunaan: 2 minit pada pemproses Nighthawk r2. (NOTA: Ini hanyalah anggaran. Masa jalan anda mungkin berbeza.)

Hasil pembelajaran​

  • Sediakan data jadual dengan lajur kategori dan berangka untuk Qiskit Function Rimay.

  • Padankan pemetaan ciri kuantum pada data latihan dan petakan data ujian dalam larian yang sama.

  • Latih model klasik pada ciri yang ditransformasi secara kuantum, secara bersendirian dan digabungkan dengan ciri asal.

  • Bandingkan keputusan dengan garis dasar klasik sepenuhnya.

Prasyarat​

Sebelum anda memulakan tutorial ini, anda sepatutnya biasa dengan topik berikut:

  • Pengenalan kepada Qiskit Functions

  • Pengelasan terselia dengan scikit-learn

Latar belakang​

Banyak masalah pembelajaran mesin dalam industri melibatkan set data jadual bersaiz kecil atau sederhana, di mana menambah lebih banyak data bukan satu pilihan dan ketepatan model mencapai dataran. Pemarkahan risiko kredit ialah contoh biasa. Pemberi pinjaman menggunakan beberapa dozen atribut untuk memutuskan sama ada pemohon berkemungkinan membayar balik kredit itu.

Rimay, sebuah Qiskit Function oleh Kipu Quantum, menambah langkah prapemprosesan kuantum pada saluran paip sedemikian. Ia melaksanakan algoritma pengekstrakan ciri kuantum kontradiabatik didigitkan [1]. Setiap ciri input dipetakan kepada satu qubit. Nilai ciri dan maklumat bersama antara ciri menetapkan medan setempat dan gandingan Hamiltonian kaca-spin. Dinamik kontradiabatik kemudian mengembangkan sistem kuantum ke arah keadaan bertenaga rendahnya, dan nilai jangkaan satu-badan dan dua-badan yang diukur pada akhirnya menjadi ciri baharu yang ditransformasi secara kuantum. Ciri ini menangkap korelasi tak linear antara input, dan anda boleh menyuapkannya kepada mana-mana model klasik.

Tutorial ini menggunakan set data kredit Jerman daripada OpenML [2], dengan 1000 pemohon dan 20 atribut, untuk melatih pengelas hutan rawak. Anda mula-mula menubuhkan garis dasar klasik, kemudian menghantar data kepada Rimay, dan akhirnya melatih jenis model yang sama pada ciri yang ditransformasi secara kuantum, secara bersendirian dan digabungkan dengan ciri asal.

from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import (
    accuracy_score,
    f1_score,
    precision_score,
    recall_score,
    roc_auc_score,
)
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import OneHotEncoder

def train_random_forest(x, y, n_estimators, max_depth):
    """Train a random forest classifier with fixed hyperparameters."""
    model = RandomForestClassifier(
        n_estimators=n_estimators,
        max_depth=max_depth,
        min_samples_split=5,
        min_samples_leaf=1,
        max_features="sqrt",
        random_state=42,
        n_jobs=-1,
    )
    return model.fit(x, y)

def evaluate(model, x, y):
    """Return the classification metrics of a trained model on a test set."""
    y_pred = model.predict(x)
    y_proba = model.predict_proba(x)[:, 1]
    return {
        "Accuracy": accuracy_score(y, y_pred),
        "AUC": roc_auc_score(y, y_proba),
        "F1 score": f1_score(y, y_pred),
        "Precision": precision_score(y, y_pred),
        "Recall": recall_score(y, y_pred),
    }

Langkah 2: Optimumkan masalah untuk pelaksanaan pada perkakasan kuantum​

Rimay membina dan men-transpile litar untuk pemproses yang anda pilih, jadi tiada litar yang perlu dioptimumkan secara manual. Nyatakan bilangan shot bagi setiap litar, dalam kekangan berikut:

  • Setiap ciri memerlukan satu qubit, jadi pemproses mesti mempunyai sekurang-kurangnya sebanyak qubit seperti bilangan ciri dalam set data.

  • Rimay menjalankan satu litar bagi setiap baris, baris latihan dan ujian bersama-sama. Satu job boleh meminta paling banyak 10 juta pelaksanaan, jadi bilangan baris darab shots mesti kekal dalam bajet tersebut.

Semak kedua-dua had sebelum anda menghantar job.

Kira saiz fungsi​

Setiap job dijalankan pada saiz fungsi, S, M, atau L, yang memilih sumber pengkomputeran yang digunakannya. Bagi Rimay, saiz bergantung pada bilangan baris yang dipetakan oleh sesuatu job, baris latihan dan ujian bersama-sama. Jika anda meminta saiz yang terlalu kecil, job gagal dengan ralat 4600. Untuk saiz dan had masing-masing, lihat Function sizes dalam panduan Rimay.

Sel berikut mentakrifkan pengira saiz. Ia berjalan pada mesin anda, hanya membaca data yang anda berikan kepadanya, dan tidak menghantar apa-apa.

from os import PathLike
from typing import Any, Literal, Sequence, Sized

Size = Literal["S", "M", "L"]

# Upper bounds (inclusive) in samples.
_SMALL = 2_999
_MEDIUM = 9_999

FIT_TRANSFORM, TRANSFORM, DELETE = "fit-transform", "transform", "delete"

# Which positions of input_file hold samples, per mode. The labels in
# y_train submit no circuits of their own, so they are not counted.
SAMPLE_POSITIONS = {FIT_TRANSFORM: (0, 2), TRANSFORM: (0,)}

def calculate_function_size(problem: Sequence[Sized], **kwargs: Any) -> Size:
    """Return the size ("S", "M" or "L") required to run the function."""
    metrics = _measure(problem, **kwargs)
    if _is_small(metrics):
        return "S"
    if _is_medium(metrics):
        return "M"
    return "L"

def _measure(problem: Sequence[Sized], **kwargs: Any) -> dict:
    """The samples the job submits."""
    return {"samples": count_samples(problem, kwargs.get("mode"))}

def count_samples(problem: Sequence[Sized], mode: Any) -> int:
    """Rows across the data sets of ``problem`` that carry samples."""
    if mode == DELETE:
        return 0
    if mode not in SAMPLE_POSITIONS:
        raise ValueError(f"cannot size mode {mode!r}")
    if _is_name(problem) or (
        isinstance(problem, (list, tuple))
        and any(_is_name(data) for data in problem)
    ):
        raise TypeError(
            "pass the data, not the file name: read each input_file, e.g. with "
            "pandas.read_csv, and pass the data sets in input_file order"
        )
    if not isinstance(problem, (list, tuple)):
        raise TypeError(
            "pass a list of data sets in input_file order, e.g. [x_train, y_train], "
            f"not a single {type(problem).__name__}"
        )
    return sum(
        len(problem[i]) for i in SAMPLE_POSITIONS[mode] if i < len(problem)
    )

def _is_name(value: Any) -> bool:
    """A file name or path rather than data."""
    return isinstance(value, (str, bytes, PathLike))

def _is_small(metrics: dict) -> bool:
    """Determine if the metrics fit T-size 'S'."""
    return metrics["samples"] <= _SMALL

def _is_medium(metrics: dict) -> bool:
    """Determine if the metrics fit T-size 'M'."""
    return metrics["samples"] <= _MEDIUM

Langkah 3: Laksanakan menggunakan primitif Qiskit​

Jalankan Rimay dalam mod fit-transform. Ia memadankan pemetaan ciri kuantum pada x_train.csv dan y_train.csv, dan memetakan kedua-dua set latihan dan ujian dengannya. Susunan fail dalam input_file adalah penting. Senaraikan ciri latihan, label latihan, dan kemudian ciri ujian pilihan. Hantar saiz yang anda kira sebagai function_size.

job = rimay.run(
    mode="fit-transform",
    input_file=[
        "x_train.csv",
        "y_train.csv",
        "x_test.csv",
    ],  # This order matters
    backend_name=backend.name,
    shots=shots,
    function_size=size,
)

Kesimpulan​

Apa yang telah anda capai​

Dalam tutorial ini, anda telah mencapai perkara berikut:

  1. Menyediakan set data risiko kredit dunia sebenar dengan atribut kategori dan berangka untuk pengekstrakan ciri kuantum.

  2. Menetapkan garis dasar random forest klasik.

  3. Menggunakan Rimay untuk memadankan pemetaan ciri kuantum pada perkakasan kuantum dan memetakan set latihan dan ujian dalam satu larian.

  4. Melatih model yang sama pada ciri yang diubah secara kuantum dan pada ciri gabungan, serta membandingkannya dengan garis dasar.

Perkara utama​

  • Rimay sesuai dimuatkan ke dalam saluran paip pembelajaran mesin sedia ada sebagai satu langkah prapemprosesan tambahan. Anda mengekalkan penyediaan data dan model klasik anda.

  • Bilangan qubit menghadkan bilangan ciri input, dan bilangan baris darab shots menghadkan saiz sesuatu job.

  • Gunakan ciri yang diubah secara kuantum yang digabungkan dengan ciri asal sebagai lalai, kerana model boleh menggunakan kedua-duanya.

Langkah seterusnya​

Cadangan
  • Baca panduan Rimay untuk mengetahui tentang semua input, memetakan data baharu dengan mode="transform", dan melihat penanda aras lanjut.
