Cari Maximum Independent Set dengan Aqarios Constrained Quantum Optimizer

Nota

Qiskit Functions ialah ciri eksperimen yang hanya tersedia untuk pengguna Pelan Premium, Pelan Flex, dan Pelan On-Prem (melalui IBM Quantum Platform API) IBM Quantum®. Ciri ini berstatus keluaran pratonton dan tertakluk kepada perubahan.

Anggaran penggunaan: 30 saat pada pemproses Heron r2. (NOTA: Ini hanyalah anggaran. Masa larian anda mungkin berbeza.)

Latar Belakang​

Tutorial ini menunjukkan cara mencari set bebas maksimum (maximum independent set) bagi suatu graf menggunakan Aqarios Constrained Quantum Optimizer [1], iaitu masalah pengoptimuman kombinatorik terkekang. Satu contoh daripada perpustakaan penanda aras QOBLIB [2] dirumuskan sebagai program linear binari dan dihantar kepada Optimizer Application Function. Optimizer ini mengendalikan semua perumusan semula, sintesis litar, transpilation, dan warm-starting berulang secara dalaman (lihat [3] untuk butiran).

Tutorial ini merangkumi langkah-langkah berikut:

  1. Takrifkan masalah sebagai program linear menggunakan OptimizationProblem daripada qiskit-addon-opt-mapper

  2. Jalankan pengoptimuman kuantum menggunakan Aqarios Constrained Quantum Optimizer

  3. Dapatkan dan visualisasikan hasilnya

Masalah Maximum Independent Set​

Masalah Maximum Independent Set (MIS) merupakan cabaran asas dalam pengoptimuman kombinatorik. Secara formal, diberikan graf G(V,E)G(V, E)G(V,E), matlamatnya adalah untuk mencari subset bucu terbesar VI⊂VV_I \subset VVI​⊂V sedemikian rupa sehingga tiada dua bucu dalam VIV_IVI​ disambungkan oleh tepi, seperti dalam ∄(u,v)∈E:v∈VI∧u∈VI\nexists (u, v) \in E : v \in V_I \wedge u \in V_I∄(u,v)∈E:v∈VI​∧u∈VI​. Setiap bucu diberikan pemboleh ubah keputusan binari xi∈{0,1}x_i \in \{0, 1\}xi​∈{0,1}, dan kekangan xu+xv≤1x_u + x_v \leq 1xu​+xv​≤1 diperkenalkan untuk setiap tepi, memastikan bahawa paling banyak satu hujung bagi setiap tepi dipilih. Masalah ini dengan itu boleh dinyatakan sebagai masalah pemaksimuman berikut:

max⁡xi∑i∈Vxi(cari set terbesar)dengan syaratxu+xv≤1∀(u,v)∈E.\max_{x_i} \sum_{i \in V} x_i \qquad\text{(cari set terbesar)}\\ \text{dengan syarat} \quad x_u + x_v \leq 1 \quad \forall (u, v) \in E.xi​max​i∈V∑​xi​(cari set terbesar)dengan syaratxu​+xv​≤1∀(u,v)∈E.

MIS mempunyai pelbagai aplikasi praktikal. Dalam perancangan rangkaian wayarles, set bebas sepadan dengan sekumpulan pemancar yang semuanya boleh menyiar secara serentak tanpa gangguan sesama sendiri. Dalam penjadualan, ia memodelkan kumpulan tugas terbesar yang boleh dilaksanakan serentak memandangkan konflik sumber berpasangan. Dalam biologi pengkomputeran, ia menangkap set protein yang tidak saling berinteraksi dalam suatu rangkaian.

Walaupun perumusannya intuitif, MIS adalah NP-hard, dan bagi graf dengan beberapa ratus nod, contoh tertentu menjadi sukar untuk diselesaikan secara tepat atau secara heuristik [2]. Masalah ini juga menghasilkan struktur kekangan jarang yang sangat sesuai untuk pelaksanaan perkakasan pengoptimuman kuantum, menjadikannya penanda aras yang menarik untuk peranti kuantum jangka pendek.

Aqarios Constrained Quantum Optimizer​

Pendekatan standard untuk membenamkan masalah binari terkekang ke dalam pengoptimuman kuantum mengubah model tersebut menjadi format tanpa kekangan dengan menambah terma penalti: setiap kekangan yang dilanggar xu+xv≤1x_u + x_v \leq 1xu​+xv​≤1 menyumbang 2xuxv2 x_u x_v2xu​xv​ kepada objektif peminimuman −∑ixi-\sum_i x_i−∑i​xi​. Ini dikendalikan secara automatik oleh Constrained Quantum Optimizer Qiskit Function.

Selain transformasi standard ini, pengoptimum mengenal pasti klik (cliques) dalam graf kekangan. Klik ialah set nod VCV_CVC​ di mana setiap pasangan nod berkongsi tepi. Akibatnya, (∣VC∣2)\binom{|V_C|}{2}(2∣VC​∣​) kekangan berpasangan xu+xv≤1  ∀(u,v)∈ECx_u + x_v \leq 1 \;\forall (u,v) \in E_Cxu​+xv​≤1∀(u,v)∈EC​ boleh digantikan dengan satu kekangan tunggal yang lebih ketat ∑i∈VCxi≤1\sum_{i \in V_C} x_i \leq 1∑i∈VC​​xi​≤1. Memperkenalkan pemboleh ubah kendur yyy mengubah ini menjadi persamaan ∑ixi+y=1\sum_i x_i + y = 1∑i​xi​+y=1, yang mengambil bentuk kekangan one-hot yang boleh dikuatkuasakan secara langsung dalam QAOA menggunakan XY-mixers [3]. Ini mengurangkan ruang carian dan mengelakkan keperluan terma penalti untuk kekangan tersebut, meningkatkan kualiti penyelesaian.

Selain itu, pemboleh ubah yang disambungkan kepada hanya satu jiran dipanggil nod pendant dan ditetapkan secara deterministik oleh algoritma sebelum pelaksanaan kuantum, seterusnya mengurangkan saiz masalah yang efektif.

Constrained Quantum Optimizer menggunakan pendekatan warm-starting berulang yang serasi dengan XY-mixers [1], yang secara beransur-ansur mengecilkan ruang carian dengan memberi bias kepada taburan keadaan kuantum ke arah kawasan penyelesaian yang menjanjikan merentasi iterasi. Ini membolehkan penggunaan parameter QAOA sudut tetap (fixed-angle), menghapuskan keperluan latihan parameter variasi. Keperluan sumber kuantum keseluruhan dikawal semata-mata oleh bilangan iterasi warm-start, yang bermakna kos kuantum mudah dikawal.

Langkah 1: Memetakan Input Klasik kepada Masalah Kuantum​

Masalah ini dirumuskan sebagai fail LP, iaitu format lazim untuk masalah pengoptimuman yang berfungsi sebagai input kepada Aqarios Constrained Quantum Optimizer. Selain fail LP, fungsi ini juga menyokong fail MPS dan representasi Luna Model asli. Fail LP dijana melalui langkah-langkah berikut:

  1. Dapatkan contoh graf daripada QOBLIB [2]

  2. Modelkan masalah pengoptimuman

  3. Jana fail LP

Muatkan Graf Contoh Masalah​

Graf-graf ditentukan dalam format DIMACS .gph, iaitu format berasaskan baris di mana baris yang bermula dengan e mentakrifkan tepi, baris yang bermula dengan p mentakrifkan pengepala masalah, dan baris yang bermula dengan c adalah komen:

c some-comment
p edge 3 2
e 1 2
e 2 3
...

Fail .gph boleh dimuat turun daripada repositori QOBLIB menggunakan fungsi berikut, yang juga menghurai (parse) fail tersebut menjadi graf NetworkX. Perhatikan bahawa format DIMACS menggunakan pelabelan nod berasaskan 1, yang ditukar kepada pengindeksan berasaskan 0 di sini.

URL_BASE = "https://raw.githubusercontent.com/ZIB-AOPT/QOBLIB/refs/heads/main/07-independentset/instances/"

def fetch_qoblib_graph(name: str) -> nx.Graph:
    """Fetch and parse the QOBLIB graph file."""
    # Download the .gph file
    file, _ = urllib.request.urlretrieve(URL_BASE + f"{name}.gph")
    with open(file) as f:
        # Read the file contents
        lines = f.readlines()

    # Skip comments
    lines = [line for line in lines if not line.startswith("c")]

    # Read graph definition
    _, _, num_nodes, num_edges = lines[0].split()
    print(f"Loading graph with {num_nodes} nodes and {num_edges} edges.")

    # Parse edge information
    # The .gph format starts node labeling with 1; we need 0 here, so we subtract one.
    split_edges = (line.split() for line in lines[1:])
    edges = [(int(u) - 1, int(v) - 1) for _, u, v in split_edges]

    return nx.Graph(edges)

graph_name = "es60fst02"
graph = fetch_qoblib_graph(graph_name)
Loading graph with 186 nodes and 280 edges.

Bina Masalah Pengoptimuman​

Masalah Maximum Independent Set boleh dirumuskan secara langsung menggunakan OptimizationProblem. Setiap nod graf menjadi pemboleh ubah keputusan binari, dan setiap tepi memperkenalkan kekangan yang memastikan paling banyak satu hujungnya dipilih:

# Create an OptimizationProblem instance
mis_problem = OptimizationProblem("MIS")

# Add a binary variable for each node
x = mis_problem.binary_var_list(graph.number_of_nodes())

# Maximize the sum of all node variables
mis_problem.maximize(linear={xi.name: 1 for xi in x})

# Add '<= 1' constraints for each edge
for u, v in graph.edges:
    mis_problem.linear_constraint({x[u].name: 1, x[v].name: 1}, "<=", 1)

Jalan pintas​

Pakej qiskit-addon-opt-mapper menyediakan kelas aplikasi yang telah dilaksanakan lebih awal untuk masalah Maximum Independent Set, yang memudahkan perumusan di atas menjadi satu panggilan sahaja:

mis = IndependentSet(graph)
mis_problem = mis.to_optimization_problem()

Langkah 3: Laksanakan menggunakan Qiskit Primitives​

Fail LP kini boleh dihantar kepada pengoptimum:

job = optimizer.run(model=lp_str, backend_name=backend.name)

print(f"Job ID: {job.job_id}")
Job ID: 87ec08b9-6275-40fa-be94-340a0a916bf1

Secara dalaman, algoritma ini melalui peringkat-peringkat berikut:

  1. Preprocessing:

    • Kurangkan pemboleh ubah yang boleh ditetapkan

    • Cari klik (cliques)

    • Kenal pasti jenis kekangan

    • Nilaikan faktor penalti untuk terma penalti

    • Guna pakai transformasi kekangan

    • Sintesiskan litar dengan kaedah penguatkuasaan kekangan

    • Penghampiran masalah dan transpilation

  2. Rantaian selari gelung berulang:

    • Sampel daripada litar dengan parameter tetap

    • Guna pakai pascapemprosesan

    • Nilai dan tetapkan kebarangkalian warm-starting yang baharu

  3. Postprocessing:

    • Cari sampel terbaik dan semak kebolehlaksanaan berkenaan masalah input

Lampiran: Pernyataan Masalah dengan Luna Model​

Selain pendekatan qiskit-addon-opt-mapper yang ditunjukkan di atas, Qiskit Function ini juga menerima model yang dicipta dengan Luna Model [4], SDK pemodelan Aqarios. Selepas pemasangan pakej PyPI luna-model, import ia seperti berikut:

Setup:

from luna_model import Model, Sense
import numpy as np

Model tersebut kemudian dibina daripada graf dengan cara yang sama seperti dengan qiskit-addon-opt-mapper: Bina model:

edges = np.array(graph.edges)

# Create the optimization model with a name
model = Model(name=f"MIS-{graph_name}", sense=Sense.MAX)
# Add binary variables
x = model.add_variables("x", graph.number_of_nodes())
# Set the objective
model.objective = x.sum()

# Use numpy like batch generation of constraints
model.add_constraints(x[edges].sum(axis=1) <= 1)

input_str = model.encode_b64()

# optimizer.run(model=input_str, backend_name="ibm_fez")

Cadangan
  • Rujuk panduan Aqarios Constrained Quantum Optimizer untuk panduan terperinci semua ciri fungsi ini.

  • Cuba pelbagai pilihan algoritma (reps, num_parallel, shots, postprocessing) pada masalah pengoptimuman binari terkekang anda sendiri untuk menilai kesannya terhadap kualiti penyelesaian dan masa larian.
