Evolusi masa Ising medan condong 2D yang di-Trotter dengan LTM AI-QEM

Anggaran penggunaan: 75 saat pada pemproses Heron r2 (LTM AI-QEM: 23 saat, ZNE: 52 saat). (NOTA: Ini hanyalah anggaran. Masa larian anda mungkin berbeza.)

Terokai rujukan API untuk spesifikasi fungsi yang terperinci.

Untuk mula menggunakan fungsi ini, ikuti panduan LTM AI-QEM.

Latar belakang​

Tutorial ini mensimulasikan evolusi masa Ising medan condong yang di-Trotter dengan fungsi LTM AI-QEM.

Pada asalnya dikonsepkan untuk memahami feromagnetisme dan peralihan fasa kuantum dalam bahan magnet, model Ising [1] telah menjadi asas fizik banyak-jasad moden. Pada peringkat asasnya, model ini menerangkan kekisi spin yang berinteraksi, dengan setiap spin boleh berada dalam satu daripada dua keadaan dan berinteraksi dengan jiran terdekatnya. Dinamik masa nyata sistem Ising dua dimensi menjadi semakin sukar untuk disimulasikan secara klasik apabila saiz sistem dan masa evolusi bertambah, yang menjadikannya medan ujian penting untuk simulasi kuantum. Selain itu, kerana Hamiltonian terdiri daripada medan satu-qubit setempat dan interaksi dua-qubit jiran terdekat, evolusi masanya boleh diwakili secara semula jadi dengan jujukan get kuantum satu-qubit dan dua-qubit. Sifat-sifat ini menjadikan model ini penanda aras yang berguna untuk mengkaji dinamik kuantum pada perkakasan masa kini dan untuk menilai keberkesanan kaedah pengurangan ralat kuantum.

Tutorial ini merangkumi langkah-langkah berikut:

  • Terangkan model Ising medan condong dan evolusi masa Trotter-nya secara matematik.

  • Tentukan Backend dan qubit untuk mensimulasikan Hamiltonian, dan visualisasikannya.

  • Tentukan Hamiltonian Ising medan condong dengan kelas Qiskit SparsePauliOp.

  • Bina litar kuantum untuk evolusi Hamiltonian dengan fungsi Qiskit evolved_operator_ansatz.

  • Tentukan boleh cerap yang sepadan dengan purata kemagnetan, sekali lagi dengan kelas SparsePauliOp.

  • Hitung evolusi purata kemagnetan bagi bilangan langkah Trotter yang meningkat dengan fungsi LTM AI-QEM.

  • Gunakan kaedah ekstrapolasi hingar-sifar (ZNE) pada keputusan QPU mentah, untuk dibandingkan dengan pengurangan yang dilakukan oleh fungsi LTM AI-QEM.

  • Senaraikan nilai purata kemagnetan yang dikira dengan algoritma dinamik Pauli jarang (SPD), yang berfungsi sebagai nilai unggul.

  • Visualisasikan semua keputusan untuk membandingkan purata kemagnetan yang dikurangkan ralatnya oleh LTM AI-QEM dengan keputusan yang tidak dikurangkan, keputusan yang dikurangkan oleh ZNE, dan keputusan daripada algoritma SPD klasik.

Model Ising medan condong dan evolusi masanya​

Hamiltonian bagi model Ising medan condong adalah seperti berikut:

dengan JJJ ialah kekuatan gandingan, dan gxg_xgx​ dan gzg_zgz​ masing-masing ialah kekuatan medan melintang dan membujur. XkX_kXk​ dan ZkZ_kZk​ ialah pengendali Pauli-X dan Pauli-Z yang bertindak pada qubit berindeks kkk. NNN ialah set indeks qubit yang berevolusi di bawah Hamiltonian. Langkah 2: Tentukan Hamiltonian​

Tentukan Hamiltonian Ising dengan kelas Qiskit SparsePauliOp. Untuk melakukannya, nyatakan sudut theta_x (θx)(\theta_x)(θx​), theta_z (θz)(\theta_z)(θz​), dan theta_zz (θzz)(\theta_{zz})(θzz​), yang masing-masing berkaitan dengan kekuatan medan melintang (g_x), kekuatan medan membujur (g_z), dan kekuatan gandingan Ising (J). Khususnya, θx=2gxΔt\theta_x=2g_x\Delta{t}θx​=2gx​Δt, θz=2gzΔt\theta_z=2g_z\Delta{t}θz​=2gz​Δt, dan θzz=2JΔt\theta_{zz}=2J\Delta{t}θzz​=2JΔt.

Gunakan kaedah SparsePauliOp.from_sparse_list untuk menginstansiasi Hamiltonian medan melintang (Hx), Hamiltonian medan membujur (Hz), dan Hamiltonian gandingan (Hzz). Kaedah SparsePauliOp.from_sparse_list menerima senarai tupel sebagai input. Setiap tupel mengandungi rentetan Pauli, indeks qubit yang dikenakan tindakan oleh pengendali Pauli dalam rentetan itu, dan pekali rentetan Pauli. Untuk butiran lanjut, lihat dokumentasi API SparsePauliOp. Indeks qubit datang daripada objek problem_nodes dan problem_edges yang ditakrifkan sebelumnya. Hamiltonian Ising medan condong yang lengkap ialah hasil tambah ketiga-tiga Hamiltonian ini.

from qiskit.quantum_info import SparsePauliOp

theta_x = 0.53
theta_z = 0.1
theta_zz = 1.0

g_x = theta_x / 2
g_z = theta_z / 2
J = theta_zz / 2

Hx = SparsePauliOp.from_sparse_list(
    [("X", [node], theta_x / 2) for node in problem_nodes],
    num_qubits=backend_num_nodes,
)
Hz = SparsePauliOp.from_sparse_list(
    [("Z", [node], theta_z / 2) for node in problem_nodes],
    num_qubits=backend_num_nodes,
)
Hzz = SparsePauliOp.from_sparse_list(
    [("ZZ", [i, j], theta_zz / 2) for i, j in problem_edges],
    num_qubits=backend_num_nodes,
)
H = Hx + Hz + Hzz

Langkah 3: Bina litar kuantum Trotter​

Sekarang, bina litar kuantum yang sepadan dengan evolusi Trotter bagi qubit dalam problem_nodes di bawah model Ising medan condong. Untuk mensimulasikan evolusi masa, bina jujukan litar kuantum dengan bilangan langkah Trotter yang meningkat (contohnya, 1, 2, dan 3 langkah). Tetapkan bilangan langkah Trotter, num_trotter_steps, kepada 10, dan cipta julat, trotter_steps, yang mengandungi nombor daripada 1 hingga num_trotter_steps.

Untuk membina litar kuantum bagi bilangan langkah Trotter tertentu, gunakan fungsi Qiskit evolved_operator_ansatz. Fungsi ini menerima Hamiltonian Ising medan condong, yang ditakrifkan sebelumnya sebagai objek SparsePauliOp, sebagai input, dan mengeluarkan litar kuantum yang sepadan dengan evolusi tersebut. Simpan litar dalam kamus, trotter_circ_dict, yang kuncinya ialah bilangan langkah Trotter dan yang nilainya ialah litar kuantum yang sepadan. Kod ini memasukkan penghalang antara langkah Trotter hanya untuk memudahkan rajah litar dibaca. Anda boleh membuang kod yang memasukkan penghalang itu.

Ambil perhatian bahawa evolved_operator_ansatz mengeluarkan litar kuantum berparameter dengan parameter t yang mengambil nilai Δt\Delta{t}Δt dalam pengendali evolusi. Oleh sebab takrifan sudut theta sudah termasuk Δt\Delta{t}Δt, tetapkan semua parameter kepada t=1.

from qiskit.circuit.library import evolved_operator_ansatz
from qiskit.circuit import Barrier, CircuitInstruction

def generate_trotter_step_circuit(ham, step):

Bandingkan keputusan​

Untuk membandingkan kaedah mitigasi, plotkan keputusan daripada LTM AI-QEM, ZNE, dan pelaksanaan perkakasan tanpa mitigasi berbanding rujukan SPD bagi setiap bilangan langkah Trotter. Kod ini juga mencetak jadual metrik prestasi utama untuk perbandingan kuantitatif.

import matplotlib.pyplot as plt
import numpy as np

def compute_improvement_metrics(
    spd_results, mitigated_evs, zne_evs, noisy_evs
):
    """Quantify how much each mitigation method improves on the unmitigated result.

    Error for each method is |SPD - method| at every Trotter step (SPD is ideal).

    Returns a dict keyed by method name with:
      - mae:               mean absolute error vs SPD
      - rmse:              root mean squared error vs SPD
      - mean_improvement:  mean(err_unmitigated - err_method)   (absolute units, >0 is better)
      - pct_improvement:   100 * (MAE_unmitigated - MAE_method) / MAE_unmitigated
      - error_reduction_factor: MAE_unmitigated / MAE_method    (>1 is better)
      - frac_steps_improved:   fraction of steps where the method beats unmitigated
    """
    spd = np.asarray(spd_results, dtype=float)
    errs = {
        "Unmitigated": np.abs(spd - np.asarray(noisy_evs, dtype=float)),
        "ZNE": np.abs(spd - np.asarray(zne_evs, dtype=float)),
        "LTM AI-QEM": np.abs(spd - np.asarray(mitigated_evs, dtype=float)),
    }
    base = errs["Unmitigated"]
    base_mae = base.mean()
    eps = 1e-12

    metrics = {}
    for name, e in errs.items():
        mae = e.mean()
        metrics[name] = {
            "mae": mae,
            "rmse": float(np.sqrt(np.mean(e**2))),
            "mean_improvement": float((base - e).mean()),
            "pct_improvement": float(
                100 * (base_mae - mae) / max(base_mae, eps)
            ),
            "error_reduction_factor": float(base_mae / max(mae, eps)),
        }
    return metrics

def plot_trotter_results(
    trotter_steps,
    spd_results,
    mitigated_evs,
    mitigated_errs,
    zne_evs,
    zne_errs,
    noisy_evs,
    noisy_errs,
    title="",
    print_summary=True,
):
    """Plot magnetization versus Trotter steps, and the absolute difference from SPD for each method.

    Top: average magnetization for each method.
    Bottom: grouped bars of |SPD - method|, with mean improvement annotated.

    Returns a dict of improvement metrics (see compute_improvement_metrics).
    """
    spd = np.asarray(spd_results)
    steps = np.asarray(trotter_steps)

    metrics = compute_improvement_metrics(
        spd_results, mitigated_evs, zne_evs, noisy_evs
    )

    series = [
        (spd_results, None, "Sparse Pauli Dynamics", "*", "green"),
        (
            mitigated_evs,
            mitigated_errs,
            "Mitigation by LTM AI-QEM",
            "P",
            "royalblue",
        ),
        (zne_evs, zne_errs, "Mitigation by ZNE", "^", "darkorange"),
        (noisy_evs, noisy_errs, "Unmitigated", "X", "red"),
    ]

    fig, (ax1, ax2) = plt.subplots(
        nrows=2, ncols=1, figsize=(12, 10), sharex=True, height_ratios=[2, 1]
    )

    for values, errs, label, marker, color in series:
        ax1.errorbar(
            steps,
            values,
            yerr=errs,
            label=label,
            marker=marker,
            color=color,
            markeredgecolor="black",
            markeredgewidth=0.5,
            ecolor="black",
            capsize=5,
        )

    ax1.set_ylabel("Average Magnetization")
    ax1.set_title(title)
    ax1.grid(alpha=0.3)
    ax1.legend()

    # Bottom: grouped bars with MAE and % improvement in the legend labels
    bars = [
        (mitigated_evs, "LTM AI-QEM", "royalblue"),
        (zne_evs, "ZNE", "darkorange"),
        (noisy_evs, "Unmitigated", "red"),
    ]
    n = len(bars)
    width = 0.8 / n
    for i, (values, key, color) in enumerate(bars):
        offset = (i - (n - 1) / 2) * width
        m = metrics[key]
        if key == "Unmitigated":
            label = f"|SPD - {key}| (MAE={m['mae']:.3f})"
        else:
            label = (
                f"|SPD - {key}| (MAE={m['mae']:.3f}, "
                f"{m['pct_improvement']:+.1f}% vs unmitigated)"
            )
        ax2.bar(
            steps + offset,
            np.abs(spd - np.asarray(values)),
            width=width,
            label=label,
            color=color,
            edgecolor="black",
            linewidth=0.5,
        )
        if key != "Unmitigated":
            pass
        ax2.axhline(
            m["mae"], color=color, linestyle="--", linewidth=1, alpha=0.8
        )

    ax2.set_xticks(steps)
    ax2.set_xlabel("Trotter Steps")
    ax2.set_ylabel("|SPD - method|")
    ax2.set_title(
        "Difference from SPD (closer to 0 is better; dashed = mean error)"
    )
    ax2.grid(alpha=0.3, axis="y")
    ax2.legend()

    fig.tight_layout()
    plt.show()

    if print_summary:
        print(
            f"{'Method':<12}{'MAE':>10}{'RMSE':>10}{'Mean impr.':>12}"
            f"{'% impr.':>10}{'Factor':>9}"
        )
        for name, m in metrics.items():
            print(
                f"{name:<12}{m['mae']:>10.4f}{m['rmse']:>10.4f}"
                f"{m['mean_improvement']:>12.4f}{m['pct_improvement']:>9.1f}%"
                f"{m['error_reduction_factor']:>9.2f}"
            )

    return None
plot_trotter_results(

    spd_results,
    mitigated_evs,
    mitigated_stds,
    zne_evs,
    zne_stds,
    noisy_evs,
    noisy_stds,
)
